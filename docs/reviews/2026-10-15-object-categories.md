# 对象类别与具体物理对象整改

业务层级统一为：对象类别 → 具体物理对象 → 试验构型 → 具体试验 → 第 N 次试验记录。

## 实现

- 左侧常驻对象类别及其下的设备，默认提供涵道风扇、电机、电推进。试验构型及后续层级在设备内容区管理。
- 类别内只创建具体物理对象；设备内只创建试验构型；试验构型内创建具体试验；具体试验内新增执行记录。删除界面中的“具体构型”设备层级及重复的类别字段。
- 保留设备自己的技术参数、单组试验构型参数、载荷谱名称或编号、可选任务书 ID。既有技术参数右侧编辑、移除模型定义和左侧专业功能的行为继续保留。
- 原始 CSV、图表及数据表均归属准确的执行记录。从记录进入专业功能自动继承设备、试验构型、具体试验及执行记录 ID。切换执行记录同步提交路由，避免快速进入分析时沿用上一条记录。

## 数据保护

存储版本升级为 5，继续使用原存储键。旧的 `configurations` 存储字段表示具体物理对象，不再增加另一层实体或复制数据；原有专业模块使用的设备 ID 保持不变。

相同类别的旧分组会合并，其旧分组 ID 作为链接别名保留。设备、试验构型、具体试验、执行记录、CSV、图表及专业成果 ID 不变。非常早期保存在父级的业务字段会保留为设备数据，不直接丢弃。既有设置与参数仍按旧迁移规则合并，多个历史记录保留为执行列表。迁移不修改输入，重复迁移不会新增副本。
