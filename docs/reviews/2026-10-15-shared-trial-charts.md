# 试验记录与共享图表成果整改

## 最终流程

执行记录保管本次 CSV。新建图表自动使用该记录内的合法 CSV 和字段，用户可以切换 CSV、轴、行范围、缩放、偏移及显示配置，生成真实预览，再命名保存或保存并导出 PNG。预览不写入成果；PNG 使用与预览相同的数据读取和绘图逻辑，并显示具体试验、记录及 CSV 来源。

具体试验详情管理执行记录，并用分页表格展示整个试验的共享图表成果。表格显示名称、来源记录和 CSV，查看后可追溯配置与原始文件，或进入来源记录调整。具体试验详情不重复提供 CSV 绘图流程。删除了“查看任务书汇总”按钮，任务书关联仍可在编辑具体试验时修改。

## 存储与兼容

- 统一权威集合为 `ConcreteTrial.charts: TrialChartResult[]`。每项保留原图表配置，增加 `sourceRecordId`，并通过 `rawFileId` 引用该记录的 CSV。
- 记录中不再存储 `charts[]`。记录页、专业来源、任务书及报告需要记录级图表时，均从试验集合按来源读取，不维护第二份库。
- 保存接口与前端表单都按整个具体试验检查重名，忽略首尾空格和英文大小写。重名要求改名，没有覆盖或自动版本机制；编辑排除当前成果自身。已有成果直接导出时同样检查名称。
- 本地存储键不变，版本从 5 升至 6。旧记录图表自动迁入所属试验，保持图表 ID、时间、模型契约、轴及处理配置、记录 ID、文件 ID；IndexedDB 文件不搬迁、不重传。更早版本经原兼容流程处理后同样迁移。
- 历史同名图表完整保留并标记，用户保存或导出前需改名。旧记录间复用图表 ID 时，通过“来源记录 ID + 图表 ID”区分，不破坏旧报告引用。迁移可重复执行，不重复建立成果。
- 报告引用原有的 `testRecordId`、`chartId` 等字段保持不变，解析器改为查找统一集合并核对来源记录。任务书读取同一集合下所有记录的成果。

主要修改：`physicalObjectStore.ts`、`PhysicalObjectsPage.tsx`、`TrialChart.tsx`、新增 `trialChartOutput.ts`，以及 `physicalBusinessContext.ts`、`PhysicalSourcePanel.tsx`、`taskTrialModel.ts`、`TaskBookWorkspace.tsx`、`ReportCreate.tsx` 的图表引用读取。没有新增依赖、后端算法或跨记录数据融合。
