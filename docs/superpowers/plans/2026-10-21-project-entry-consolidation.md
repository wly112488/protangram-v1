# 试验创建入口与统一成果界面实施计划

**Goal:** 独立入口创建不属于 Project 的单个具体试验；项目入口创建时自动关联当前 Project。取消空会话的提前持久化，统一成果浏览。

**Architecture:** 保留 PhysicalObjectStore 的原始试验/记录/CSV 和 ProjectArtifact；共享页只投影来源，不复制数据。项目页通过 URL 区分试验列表和共享成果。会话是具体试验工作入口，只有试验提交成功后才创建，不另增“工作笔记”创建流程。

**Tech Stack:** React、TypeScript、Ant Design、Zustand、Node test runner、Playwright。

## 约束与验证边界

- 以用户最新澄清为准：具体试验可以从独立、项目和任务书入口创建，Project 不是前置条件。
- 最近会话加号、工作台创建按钮及旧 /sessions/new 地址均进入同一具体试验表单；无 projectId 时创建独立试验，不自动建立组织项目。
- 从项目进入时固定项目上下文；从任务书进入时自动关联任务书，可无项目；显式失效的项目/任务链接不能静默转为独立创建。
- 未提交/无效提交不创建试验和会话；明确保存的上级对象独立保留。
- 不改后端模型、不迁移或清理用户已有数据；当前存储为本机，界面不得宣称数据库保存成功。
- 成果全量保留稳定 ID；项目/试验筛选不使用名称猜测、不覆盖历史成果。
