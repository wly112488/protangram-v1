# 会话内专业功能、通用工具与共享成果

**执行状态：已完成本轮前端实现。** 184 个用例、构建和六组隔离浏览器验收通过；Lint 与同环境基线一致。详见[验收记录](../../verification/2026-10-23-session-generic-and-cfg-resources.md)。

本轮确认的规则覆盖先前“所有操作必须先创建具体试验”的限制。

- 专业功能都由用户选择 CFG；具体试验为可选业务上下文。
- 虚拟工况先浏览/选择 MODEL，再在模型配置内选择 CFG，不提前弹 CFG 选择器。
- 通用工具合并提供数据导入、编辑和绘图，数据与成果归当前会话。
- 专业成果归 CFG，并在当前会话共享目录引用；同一 CFG 可被多个会话使用。
- 当前会话的共享目录以“通用”和各个 CFG 分组；不显示“CFG：无”“关联会话”等冗余说明。
- 来源与归属独立；CFG 下的 CSV、图表不必关联 MODEL。
- 保留已有 localStorage、IndexedDB、具体试验及旧成果。本轮沿用现有前端持久化，记录显式归属及引用，不新增推测的生产接口。

实施：先增加归属/引用与目录纯逻辑测试，再统一专业上下文、调整模型入口，复用 CSV 编辑器创建通用工具，最后进行构建、回归和隔离浏览器验收。
