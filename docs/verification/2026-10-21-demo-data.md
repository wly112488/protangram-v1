# 固定演示数据

样例定义保存在 `frontend/src/workspace/demoData.ts`，随 Git 仓库分发。首次打开当前版本会自动追加到浏览器原有存储：

- 两台涵道风扇，每台两个试验构型，包含设备参数及构型参数。
- 四个具体试验：两个独立会话、两个项目内会话；一个试验包含两次执行，首次执行包含两个 CSV。
- 六个 CSV，每个 120 行、五列；图表与数据表引用原执行记录及 CSV，通过现有 IndexedDB 文件读取与绘图功能打开。
- 一个正式任务，包含五个事项、已确认试验模板及 2/5 的完成进度。
- 智能试验设计、分析、数字孪生、虚拟工况及报告的固定成果样例，通过既有共享目录查看。样例明确标记为演示成果，不进入真实 CSV 异常诊断结论。
- 分析任务书页可使用内置文本样例，自动填写待复核模板及事项。

初始化使用稳定 ID，仅追加不存在的记录。完成标记写入后，刷新不会重复创建，也不会恢复用户主动删除的样例。已有记录与修改保留，CSV 正文存入原 IndexedDB 文件库，不塞入 localStorage。正式部署可设置 `VITE_DEMO_DATA=false` 禁用自动初始化。

验证：构建、改动文件 ESLint、原有 146 项 `.mjs` 测试、两项新增数据关系与可复现性测试通过。浏览器检查自动初始化、底部 CSV 表格、共享目录实际绘图、任务进度、样例任务书导入、刷新无重复及无运行时错误。

所有样例数值均为合成展示数据，不代表真实实测或后台计算。现有后端接口及数据模型未改变；GitHub 保存样例定义，浏览器保存演示时的编辑。
